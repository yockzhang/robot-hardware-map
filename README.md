# Robot Hardware Map

An interactive map of what it takes to learn robot hardware from zero: six stops,
each part with a real photo or diagram, what it does, and which day of the series covers it.

**Live:** https://yockzhang.github.io/robot-hardware-map/

Part of *Robot Hardware from Zero*, a learn-in-public series by Yock (Shudi Zhang).
